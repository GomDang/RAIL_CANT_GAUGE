사용하는 스마트폰을 선택하세요

기종에 따라 센서 권한 요청 방법과 초기 부호 설정이 다릅니다. 나중에 도움말에서 바꿀 수 있습니다.

스마트폰 거치 방법

  1. 화면이 하늘을 향하게 놓으세요.
  2. 스마트폰의 긴 방향을 수평계와 나란히 맞추세요.
  3. 충전포트(USB-C)가 수평계 끝 쪽을 향하게 하세요.
  4. 스마트폰이 놓인 쪽 레일이 높으면 +, 낮으면 − 로 표시됩니다.

    도움말

    부호 규칙

    스마트폰이 놓인 쪽 레일이 높으면 +, 낮으면 − 입니다. 수평계를 좌우 반전하면 값의 크기는 같고 부호만 바뀝니다.

    측정 방법

    실시간: 흰색은 값이 흔들리는 중, 노란색은 안정된 상태입니다. 안정되면 숫자를 고정하고, 실제 변화가 일정 크기 이상일 때만 바꿉니다.

    [측정]: 몇 초 동안 평균을 내서 값을 고정합니다. 진동이 있는 현장에서는 이 값을 읽고 [저장]하세요. [실시간]을 누르면 다시 실시간 표시로 돌아갑니다.

    흔들림 ±: 값이 흔들리는 폭입니다. 이 값이 크면 진동이 큰 상태입니다.

    캔트 환산

    레일두부 중앙 사이 1500mm에서 측정한 높이차를 1435mm 기준으로 환산하여 표시합니다. 캔트 = 1435 × sin(기울기)

    정확도 안내

    표시는 0.1mm 단위이지만, 실제 정확도는 스마트폰 센서 성능에 따릅니다. 소수점이 조금씩 움직이는 것은 센서 잡음 때문이며 고장이 아닙니다.

    현장 사용 유의사항
    1. 레일두부 위의 이물질(자갈 가루, 기름)을 닦고 올려놓으세요.
    2. 수평계를 레일에 직각으로 놓으세요.
    3. 폰을 거치대에서 다시 끼웠다면 반전검증을 다시 하세요.
    4. 장비 가동 중에는 민감도를 "낮음"으로 하고 [측정] 값을 사용하세요.
    화면 회전

    폰을 돌려도 앱 화면은 세로로 유지됩니다. 아이폰은 제어 센터에서 세로 방향 잠금을 켜두면 화면이 아예 돌아가지 않아 더 편리합니다.
